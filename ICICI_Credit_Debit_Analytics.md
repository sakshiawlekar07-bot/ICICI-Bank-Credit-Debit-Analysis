# ICICI Bank Credit and Debit Analytics Dashboard \| Microsoft Excel

## Project Overview

Developed an interactive Credit and Debit Analytics Dashboard for ICICI
Bank using Microsoft Excel. The dashboard helps explore transaction
activity, compare money coming into and going out of accounts, and
review transaction patterns across different dimensions.

The analysis focuses on credit inflows, debit outflows, net cash flow,
and transaction trends by month, bank, branch, transaction category, and
transaction method.

## Tools & Techniques

-   Microsoft Excel
-   PivotTables and PivotCharts
-   Excel formulas and KPI calculations
-   Slicers and interactive filters
-   Data cleaning and analysis
-   Data visualization

## Key Performance Indicators

The dashboard includes 15 KPI metrics. Key examples displayed in the
project include: - **Total Credit:** approximately ₹127.6M - **Total
Debit:** approximately ₹127.3M - **Net Cash Flow:** approximately
₹318,117

Other KPI cards include average transaction value and average account
balance.

## Dashboard Analysis

The dashboard supports analysis of: - Credit inflows compared with debit
outflows - Net cash flow - Monthly transaction patterns - Transaction
activity by bank - Branch-wise transaction activity - Transaction
categories - Transaction methods - Average transaction value - Average
account balance

Interactive branch slicers and other dashboard filters allow users to
explore the metrics and charts for selected segments.

## Project Objective

The objective of this project is to understand transaction activity,
compare credit and debit movements, monitor cash flow, and identify
patterns across months, banks, branches, transaction categories, and
transaction methods.
