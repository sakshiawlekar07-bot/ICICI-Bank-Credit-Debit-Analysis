# ICICI Bank Loan Analytics Dashboard \| Microsoft Excel

## Project Overview

Created an interactive Bank Loan Analytics Dashboard in Microsoft Excel
to explore loan portfolio performance, repayment activity, borrower age
groups, loan terms, loan status, monthly funding trends, and loan
purposes.

The dashboard brings key lending metrics and visual summaries together
to help users monitor the loan portfolio and understand patterns in the
available data.

## Tools & Techniques

-   Microsoft Excel
-   PivotTables and PivotCharts
-   Excel formulas and KPI calculations
-   Slicers / interactive filters
-   Data analysis and visualization

## Key Performance Indicators

**Interest Received:** KPI card included in the dashboard; the

## Dashboard Analysis

The dashboard includes visualizations for: - **Loan Distribution by Age
Group** -- compares loan distribution across borrower age groups. -
**Loan Term Distribution** -- shows the split between 36-month and
60-month loan terms. - **Loan Status Breakdown** -- compares loan counts
across statuses such as Active Loan, Fully Paid, Net-Off, Transferred,
Paid Off, Insurance Paid Off, Cancelled, NPA, and Write Off. - **Monthly
Loan Funding Trend** -- tracks loan funding over time. - **Top 10 Loan
Purposes by Amount** -- highlights the purposes receiving the highest
loan amounts.

Interactive slicers allow users to filter the dashboard and explore
different segments of the loan data.

## Project Objective

The objective is to summarize important loan portfolio metrics, examine
funding and repayment patterns, and make loan trends easier to explore
through an interactive Excel dashboard.
